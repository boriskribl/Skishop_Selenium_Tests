# SkiShop Selenium Tests

Automated tests for the Ski Shop web application using Python, Pytest and Selenium WebDriver.

## Technologies

- Python
- Pytest
- Selenium WebDriver
- Google Chrome

## Tests included

- User login authentication
- Ski equipment search
- Admin users table display
- Add equipment form display

## Running the tests

Make sure the Ski Shop application is running locally at:

`http://localhost/ski_shop`

Then run:

```bash
pytest test_skishop.py
```
